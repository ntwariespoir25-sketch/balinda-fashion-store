# Changelog

All notable changes to the Balinda Fashion Store demo.

## [1.0.0] — 2026-09-12

### Added
- Full product catalog (16 items, 4 categories) with stock, colours, ratings.
- Cart drawer with quantity controls, localStorage persistence, promo codes
  (`BALINDA10`, `NEWSEASON`, `FREESHIP`) and free-shipping progress bar.
- Multi-step checkout demo with form validation.
- Quick-view modal with size selection.
- Wishlist with counter and wishlist-only browsing.
- Recently-viewed strip, search suggestions, result counter, 6 sort modes.
- Marketing sections: testimonials, press marquee, Instagram gallery, countdown.
- Scroll reveal animations, skeleton shimmer, reading progress, back-to-top.
- SEO/social tags, favicon, web manifest, robots.txt, sitemap.
- Accessibility: skip link, focus styles, reduced-motion support, live regions.
